# Avery Institute launch checklist

Complete this once after Manus deploys the finished ZIP.

- [ ] Home, About, Store, coaching/service, account, and policy sections open on desktop and phone.
- [ ] Public visitors can see every published Store resource without an administrator login.
- [ ] Uploading one PDF fills the title, detailed description, category, recovery topic, format, page count, keywords, and suggested price; every field remains editable.
- [ ] The administrator resource list shows six items per page with working page controls.
- [ ] The selected free packet remains private and downloads only after signup or sign-in.
- [ ] Email consent is optional; both consented and non-consented visitors can receive the free packet.
- [ ] The administrator can view free-packet requests and export only consented email contacts.
- [ ] A custom promotion can be saved, previewed, duplicated, scheduled, activated, and deactivated.
- [ ] Start/end times automatically control both the visitor banner and the server-calculated PDF discount.
- [ ] Once-per-campaign, once-daily, and every-new-visit popup settings behave as labeled.
- [ ] Views, clicks, attributed signups, and verified purchases appear on the correct campaign.
- [ ] A test Stripe purchase shows the correct discount, returns successfully, and provides a secure PDF download.
- [ ] Existing Supabase resources, bundles, previews, customer accounts, Stripe settings, and the current domain are unchanged.
